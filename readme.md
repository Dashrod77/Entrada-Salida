Problema 2: Entrada/Salida - Nivel 0

Objetivo:
Entender cómo un programa recibe datos del usuario (entrada) y realiza operaciones aritméticas con esos datos.

Problema:
Crea un programa que:

Pida al usuario DOS números (usa cin)
Calcula: suma, resta, multiplicación, división, módulo
Almacena los resultados en variables
Imprime todos los resultados con etiquetas claras

Ejemplo de salida esperada:

Ingresa el primer número: 10
Ingresa el segundo número: 5

RESULTADOS:
Suma: 15
Resta: 5
Multiplicación: 50
División: 2
Módulo: 0

Otro ejemplo:

Ingresa el primer número: 20
Ingresa el segundo número: 7

RESULTADOS:
Suma: 27
Resta: 13
Multiplicación: 140
División: 2
Módulo: 6
